# NullBot UI v0.4.0

A desktop workflow update focused on smoother chat, visibility into agent activity, attachments, and explicit project access. This release incorporates the latest merged `main` changes from NullBot UI, NullBot, and Tinychain.

## Highlights

- **Smoother chat:** coordinated submissions, improved busy/queued handling, pause/resume controls, composer undo/redo, and safer session loading.
- **All-agent Live Activity:** see model and agent activity beyond the primary reply, including streaming lifecycle events. The activity view retains the latest 80 events.
- **More reliable transcripts:** improved streaming reconciliation, tool-event deduplication, scrolling, and reasoning-summary display persistence.
- **Attachments:** import files and pasted/path-based attachments with image previews. Filename/path validation, a 20 MiB per-file limit, and image pixel limits protect the staging workflow.
- **Projects and permissions:** project-aware workspace access with additional Windows path, junction, symlink, and reparse-point checks. Project MCP discovery requires full access.
- **Skills and model workflow:** skill selection and opt-in automatic matching, plus project/model assignment improvements.

## Runtime and release fixes

- Updated NullBot and Tinychain to immutable public main-branch revisions supporting the coordinated submission and streaming APIs; no sibling checkout or local Go replacement is needed.
- Fixed NullBot's Tinychain dependency pin so its merged streaming imports resolve independently.
- Fixed a CRLF-sensitive frontend test on Windows.
- Added consistent 0.4.0 package/Windows version metadata and lockfile-based frontend installation.
- Added curated changelogs and release instructions under `docs/`; local release automation and generated release output remain gitignored.

## Download and upgrade

Windows x64 assets:

- `nullbot_ui.exe` — standalone application executable.
- `nullbot_ui-windows-amd64.zip` — the same executable in a ZIP.
- `SHA256SUMS.txt` — SHA-256 checksums for both downloads.

Close the previous application before replacing it. Keep your existing user configuration and credentials private; they are not included in these downloads. The Windows application uses Microsoft Edge WebView2 Runtime. This release does not provide macOS/Linux binaries or a signed Windows installer.

```powershell
Get-FileHash .\nullbot_ui.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt` before running.

## Validation and limitations

Release validation covers Go test suites for the three repositories, frontend regression tests, a production Windows amd64 build, module verification, explicit archive contents, and heuristic credential-pattern checks. Interactive GUI and live-provider end-to-end behavior are not certified by these automated checks. Stream/reasoning availability depends on the selected provider; path checks are defense in depth, not an operating-system sandbox. Windows SmartScreen may warn about an unsigned download.
