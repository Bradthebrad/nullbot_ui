# NullBot UI v0.5.0

A redesign of the desktop app around two ideas: you can see and steer
everything the agent does, and you can answer it in text or through
interactive visuals. Built on NullBot v0.5.0 and tinychain v0.3.0.

## Highlights

- **Interactive visuals.** A new `visualize` tool lets the agent open a window
  beside the conversation: polls, web pages and prototypes, pictures to label,
  Chart.js charts, draw.io diagrams and any project file. Everything you do in
  it is recorded (clicks, form changes, page moves, script errors), and
  **Send to NullBot** returns your answer, your note and the interactions. Use
  it to settle preferences, label data, test a UI the agent built, or play a
  small game. Windows can be tabbed, maximized or minimized to a pill.
- **Visuals page.** Every visual, by project, with what was sent back and a
  timed replay of the interactions. Visuals are saved in the project under
  `.nullbot/visualizations` (kept out of Git), signed so a copied or edited
  record is ignored.
- **A new desktop shell.** A rail for Chat, Activity, Files, Visuals, Tools,
  History and Settings; the primary project and model in the top bar with the
  run state and tool health; light, dark and system themes with five accents;
  a command palette on `Ctrl+K` and views on `Ctrl+1` to `Ctrl+6`.
- **A readable live trace.** Each tool call reads as a sentence ("Searched
  issues…", "Blocked: writing…") with its duration, source and result. A call
  a project's permission stops explains why and links to the setting. Links in
  answers open safely: web and mail links in your browser, local paths in
  Files.
- **Run controls.** Pause, stop after this step, or stop everything. Steer a
  running request, or one subagent from Activity; ask a question on the side;
  queue the next request.
- **Context you can see.** A meter by the composer shows how full the model's
  window is and when NullBot will shorten old tool results or summarize; the
  transcript marks where a conversation was compacted. Settings > Agent holds
  the thresholds and how much of the conversation a new request carries.
- **Models for each role.** The manager and the subagents each get a
  provider, model, thinking effort, reply limit and context window, with the
  window filled in from the provider or a built-in table.
- **Files.** Project tabs with their permission, recursive search with type
  filters, back and forward, cut/copy/paste/duplicate/rename/delete, and
  previews for Markdown, code, JSON, CSV, spreadsheets, Word, PowerPoint,
  OpenDocument, RTF, PDF, pictures, audio, video, fonts and archives.
- **History.** Search every saved session's messages and tool calls, filter
  by kind and date, see where each match is, and continue the conversation.
- **Marketplace.** Versions come from each package's release; permissions
  read in plain words; packages without a release are marked as not released
  instead of failing to install. New skill packs: web search, web tools,
  browser automation and browser research.
- **Skills from the `/` menu** are attached to the message instead of typed
  into it.

## From the runtime (NullBot v0.5.0, tinychain v0.3.0)

- Every tool call, built in or from a local or remote MCP server, is checked
  against the permission of the project it touches. Paths outside every
  project are refused before any file access.
- Tool servers start once, in parallel, and are shared by the manager,
  subagents and side questions; they restart after a crash and stop when idle.
- Sessions now save their tool calls, and agents can search all history.
- Context is managed per model in two tiers, with a guard on every tool
  result; `/compact` and the palette's Compact run the same passes on demand.
- Service accounts for the email, drives and messages servers (Gmail by API or
  IMAP/SMTP, Outlook, Google Drive, OneDrive, iCloud Drive folders, Twilio,
  WhatsApp Business, Discord, Telegram and a local Signal bridge), stored with
  Windows DPAPI and passed only to the matching server installed from the
  Marketplace. Those three servers are not released yet.
- NullBot can also run headless (`nullbot -p`, `nullbot serve`); see the
  NullBot release.

## Download and upgrade

Windows x64 assets:

- `nullbot_ui.exe`: the application.
- `nullbot_ui-windows-amd64.zip`: the same executable in a ZIP.
- `SHA256SUMS.txt`: SHA-256 checksums for both.

Close the previous version before replacing it. Your settings, keys and
history stay in your NullBot folder and are not part of the download. The app
uses the Microsoft Edge WebView2 Runtime. There are no macOS or Linux builds
and no signed installer yet.

```powershell
Get-FileHash .\nullbot_ui.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt` before running.

## Validation and limitations

Checked for this release: the Go test suites of NullBot UI, NullBot and
tinychain; the frontend unit and Node tests; a production Windows amd64 build;
and pattern scans of the source, history and README images for credentials
and personal data. The UI screenshots were taken from the production frontend
against sample data. Interactive end-to-end use and live providers are not
covered by these checks. Visuals' pages are isolated in a sandboxed frame, but
a page can still navigate its own frame to a web address; treat a visual like
any page you open. Windows SmartScreen may warn about an unsigned download.
